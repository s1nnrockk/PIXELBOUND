# PIXELBOUND
A pixel-art stealth character prototype in a 3D test scene, built with Godot 4.

## Controls
- WASD / arrow keys: move
- Shift: sneak

## Build
GitHub Actions exports Windows and Linux builds on pushes to `main` and manual dispatch. Download the `PIXELBOUND-build` artifact from Actions.

## Prototype
- Procedurally drawn 24×32 pixel hooded character
- Idle breathing and four-frame walk cycle
- Pixelated sprite rendered in a 3D scene and affected by real-time colored lights
- Warm, cyan, purple and directional lighting for visual tests
- Ground contact shadow plus light-cast shadow
